# Documentação do VYBE

Este diretório concentra as informações, regras, referências de design, decisões e planejamento do projeto.

## Índice

- [Visão geral](visao-geral.md): propósito, público e escopo do produto.
- [Regras](regras.md): regras do produto e acordos de trabalho.
- [Design](design/README.md): experiência, interface e referências visuais.
- [Decisões](decisoes/README.md): histórico das decisões e suas justificativas.
- [Roadmap](roadmap.md): próximos passos e prioridades.

## Como manter a documentação

- Atualize o documento correspondente quando uma definição mudar.
- Identifique propostas e pontos em aberto; não os apresente como decisões aprovadas.
- Registre decisões relevantes com contexto, alternativas e consequências.
- Use links relativos para conectar documentos e referências.
- Não inclua senhas, tokens, credenciais ou dados pessoais sensíveis.

Os tópicos marcados como **A definir** ainda não representam requisitos aprovados.
